## Why a revised copy instead of editing the master in place

The v1.0 master lives outside the repository (the owner's Downloads folder) and is the baseline the executives are reviewing.
The v1.1 file is built from the v1.0 file. Its structure (sections 00–25, Appendices A–E), styles, header and footer are kept, and every change is a Word tracked change.
Reviewers accept or reject changes individually, and v1.0 stays untouched as the approved-for-review baseline.
